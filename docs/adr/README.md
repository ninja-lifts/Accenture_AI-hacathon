# Architecture Decision Records

Short records of decisions with trade-offs, not just outcomes. Judges assessing
engineering want to see that a choice was *made*, with the cost named.

Each one doubles as Q&A preparation — if you are asked "why didn't you use X",
the answer is already written, already argued, and already committed.

| [0004](0004-synthetic-primary-dataset.md) | Synthetic data as the primary benchmark |
| [0005](0005-rule-assigned-tiers.md) | Tiers assigned by rule, not by model |

Add one whenever you decline something obvious. A recorded "no" is worth more
than a silent absence.
